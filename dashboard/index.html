Token Launch Radar radar-5

Every protocol in the snapshot is accounted for. Every price on the board comes from a model fitted on this snapshot and tested held-out — the tests are printed below, and the strip under them recomputes the board's own claims from the data file, live. Each row also carries its launch window — the age at which the fitted peer odds say a protocol like it typically records a token — so a farm plan can be timed, not just priced.

Implied value is this entry's own fitted claim, never a prediction that a token will be issued. The launch window is a timing readout from the same fitted odds — the age by which half of like peers already record a token — not a promise that this protocol will issue one, or when. A protocol is said to record no token, never to have none: DefiLlama's record is the evidence, and it can lag.
